# Rhishi Kumar Ayyappan · AI Risk Analyst

Personal portfolio site. Plain HTML, CSS and JavaScript with no build step.

- `index.html`: content (edit text here)
- `styles.css`: design tokens and layout
- `script.js`: scroll reveals, metric count-up and the live "trust gate" console in the hero

## Run locally

Open `index.html` in a browser, or serve it:

```sh
python3 -m http.server 8000
```

## Deploy (GitHub Pages)

Settings → Pages → Source: *Deploy from a branch* → pick the branch and `/ (root)`.
The site will be live at `https://rhishikumarayyappan.github.io/portfolio/`.
